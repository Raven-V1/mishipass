## Notes

- Active HTML surfaces are served from the worker app, not `apps/web`.
- The strongest structural issue is that `apps/worker/src/pages/dashboard.ts` currently renders both the dashboard and registration experience.
- Authenticated subpages frequently render both `renderTopNav(...)` and `brandLockupHtml(...)`, which creates a duplicated header pattern relative to the mockups.
- No local approved Adoption mockup image was found under `assets/mockups`; adoption source selection must rely on the newest approved local route/design context in the repository unless a newer design asset is added.
